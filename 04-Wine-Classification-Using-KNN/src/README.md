# Source Code

This directory contains the implementation of the Wine Classification project using the K-Nearest Neighbors (KNN) algorithm.

## Features

- Dataset Loading and Preprocessing
- Missing Value Handling
- Feature Scaling using StandardScaler
- K Value Optimization
- Wine Classification using KNN
- Model Evaluation
- Accuracy Analysis
- Confusion Matrix 
- Classification Report
- Performance Visualization
