# 📸 Project Screenshots

This folder contains screenshots of the outputs and visualizations generated during the Wine Classification project using the **K-Nearest Neighbors (KNN)** algorithm.

The screenshots demonstrate the execution of the Machine Learning workflow, model evaluation, and visualization of classification performance.

## 📊 Screenshot Details

### 1. Program Execution Output

Displays the terminal output generated during the execution of the Wine Classification program.

The output includes dataset information, data preprocessing, model training, predictions, and evaluation results.
 
### 2. K-Value Accuracy Visualization

Displays the relationship between the number of neighbors (`K`) and model accuracy.

This visualization helps identify a suitable K value for the KNN classification model.

### 3. Confusion Matrix

Displays the confusion matrix generated after evaluating the trained KNN model.

The matrix compares actual wine classes with predicted wine classes to help understand the model's classification performance.

### 4. Classification Report

Displays the classification evaluation metrics, including:

- Precision
- Recall
- F1-Score
- Support

These metrics provide additional information about the model's performance for each wine class.

### 5. Project Summary

Displays the final project summary, including the selected K value, model accuracy, algorithm, and problem type.
