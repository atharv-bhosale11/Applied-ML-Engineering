# Dataset

This folder contains the dataset used for the Wine Classification project.

## Dataset Information

- Dataset Name: Wine Dataset
- File Name: Wine.csv
- Total Samples: 178
- Total Features: 13
- Target Classes: 3

## Features

- Alcohol
- Malic Acid
- Ash
- Alcalinity of Ash
- Magnesium
- Total Phenols
- Flavanoids
- Nonflavanoid Phenols
- Proanthocyanins
- Color Intensity
- Hue
- OD280/OD315 of Diluted Wines
- Proline

## Target

The target variable represents the class of wine:

- Class 0
- Class 1
- Class 2

## Purpose

This dataset is used to train and evaluate the K-Nearest Neighbors (KNN) classification model for predicting the wine class based on its chemical properties.
