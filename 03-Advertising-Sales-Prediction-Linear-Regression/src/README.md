# Source Code

This folder contains the implementation of the Advertising Sales Prediction project using Linear Regression.

## File

- `AdvertisingSalesPrediction.py` - Complete workflow including data preprocessing, model training, evaluation, and visualization.

## Features 

- Data Cleaning
- Missing Value Analysis
- Correlation Analysis
- Linear Regression Model
- Performance Evaluation (MSE, RMSE, R² Score)
- Actual vs Predicted Sales Visualization
