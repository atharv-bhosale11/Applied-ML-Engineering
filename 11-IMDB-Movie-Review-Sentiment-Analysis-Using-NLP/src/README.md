# IMDB Movie Review Sentiment Analysis Using NLP

## 📌 Overview

This directory contains the Python source code for the IMDB Movie Review Sentiment Analysis project. The project uses Natural Language Processing (NLP) and Machine Learning techniques to classify movie reviews as positive or negative.

## 📂 Source File

| File Name                   | Description                                                             |
| --------------------------- | ----------------------------------------------------------------------- |
| `IMDB_SentimentAnalysis.py` | Main Python script containing the complete sentiment analysis workflow. |

## ⚙️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Natural Language Processing (NLP)
* Joblib

## 🔄 Project Workflow

1. Project setup and path configuration.
2. Dataset loading and inspection.
3. Dataset structure validation and cleaning.
4. Sentiment distribution analysis.
5. Review length analysis.
6. Common word exploration.
7. Text cleaning and preprocessing.
8. Sentiment label encoding.
9. Text feature extraction using TF-IDF.
10. Training and testing data splitting.
11. Baseline model development.
12. Machine learning pipeline creation.
13. Model comparison using cross-validation.
14. Hyperparameter tuning.
15. Final model training and evaluation.
16. Misclassified review analysis.
17. Model performance visualization.
18. Sentiment prediction for new reviews.
19. Model and output saving.
20. Final project summary.

## ▶️ Execution

Run the main Python script from the project environment:

```bash
python IMDB_SentimentAnalysis.py
```

Ensure the required Python libraries are installed and the IMDB dataset is available at the configured path.

## 📊 Outputs

The project generates the following outputs:

* **Model:** `models/sentiment_model.joblib`
* **Visualizations:** `images/`
* **Evaluation metrics:** `results/evaluation_metrics.csv`
* **Model comparison:** `results/model_comparison.csv`
* **Misclassified reviews:** `results/misclassified_reviews.csv`
