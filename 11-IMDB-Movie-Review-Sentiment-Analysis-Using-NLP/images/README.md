# IMDB Sentiment Analysis — Visualizations

## 📌 Overview

This directory contains visualizations generated by the **IMDB Movie Review Sentiment Analysis Using NLP and Machine Learning** project.

These visualizations help explore the dataset, understand sentiment patterns, compare model performance, and evaluate the final sentiment classification model.

## 📂 Images in This Directory

| No. | File Name                        | Description                                                                                       |
| --- | -------------------------------- | ------------------------------------------------------------------------------------------------- |
| 1   | `sentiment_distribution.png`     | Visualizes the distribution of positive and negative movie reviews in the dataset.                |
| 2   | `review_length_distribution.png` | Shows the distribution of review lengths by sentiment, measured by the number of words.           |
| 3   | `common_words_positive.png`      | Displays the 20 most common words in positive movie reviews.                                      |
| 4   | `common_words_negative.png`      | Displays the 20 most common words in negative movie reviews.                                      |
| 5   | `confusion_matrix.png`           | Visualizes the final model's classification results, including correct and incorrect predictions. |
| 6   | `model_evaluation_metrics.png`   | Displays the final model's accuracy, precision, recall, and F1-score.                             |

## 📊 Visualization Details

### 1. Sentiment Distribution

**File:** `sentiment_distribution.png`

Displays the number of positive and negative reviews in the IMDB dataset.

**Purpose:** Understand the distribution of sentiment labels and check whether the dataset is balanced.

### 2. Review Length Distribution

**File:** `review_length_distribution.png`

Displays the distribution of movie review lengths for positive and negative reviews.

**Purpose:** Understand differences in review length and identify the typical length and spread of the reviews.

### 3. Common Words in Positive Reviews

**File:** `common_words_positive.png`

Displays the 20 most frequently occurring words in positive reviews.

**Purpose:** Explore frequently used words in reviews expressing positive sentiment.

### 4. Common Words in Negative Reviews

**File:** `common_words_negative.png`

Displays the 20 most frequently occurring words in negative reviews.

**Purpose:** Explore frequently used words in reviews expressing negative sentiment.

### 5. Confusion Matrix

**File:** `confusion_matrix.png`

Shows the relationship between actual sentiment labels and the model's predicted sentiment labels.

**Purpose:** Examine correct predictions and misclassifications for both positive and negative reviews.

### 6. Final Model Evaluation Metrics

**File:** `model_evaluation_metrics.png`

Displays four model evaluation metrics:

* **Accuracy:** The proportion of all predictions that are correct.
* **Precision:** The proportion of predicted positive cases that are actually positive.
* **Recall:** The proportion of actual positive cases correctly identified.
* **F1-score:** The harmonic mean of precision and recall.

**Purpose:** Summarize the final model's classification performance.
