# Source Code

This directory contains the implementation of the Sports Ball Classification Case Study.

## File Information

### sports_ball_classification.py

This file contains the complete Machine Learning workflow:

- Dataset Loading
- Data Preparation
- Model Training
- Model Testing
- Prediction
- Accuracy Evaluation
- Result Display

## Algorithm Used

- Decision Tree Classifier

## Features

- Weight (grams)
- Surface Type

## Surface Encoding

| Surface | Value |
|----------|--------|
| Rough | 1 |
| Smooth | 0 |

## Ball Type Encoding

| Ball Type | Value |
|-----------|--------|
| Tennis Ball | 1 |
| Cricket Ball | 2 |

## Functions

| Function | Purpose |
|-----------|----------|
| DisplayData() | Displays project header |
| LoadDataSet() | Loads dataset |
| PreparedData() | Prepares training and testing data |
| TrainModel() | Trains Decision Tree model |
| TestModel() | Calculates model accuracy |
| PredictBall() | Predicts ball category |
| DisplayResult() | Displays prediction |
| DisplayFooter() | Displays completion message |
| main() | Controls application flow |
