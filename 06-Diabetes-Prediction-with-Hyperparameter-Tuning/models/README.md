# Trained Model — Diabetes Prediction

This directory is intended to store the trained machine learning model generated by the **Diabetes Prediction with Hyperparameter Tuning** project.

## Model File

| File | Description |
|---|---|
| `BestDiabetesModel.pkl` | Serialized machine learning pipeline containing the selected classification model and its preprocessing steps. |

## Best Model Selection

The project evaluates five classification algorithms using hyperparameter tuning and stratified 5-fold cross-validation:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

The algorithm with the highest mean cross-validation accuracy is selected as the best model.

In the current execution, **Logistic Regression** was selected with a best cross-validation accuracy of **78.99%**.
