# Project Screenshots

This directory contains screenshots demonstrating the execution, model optimization, and evaluation results of the **Diabetes Prediction with Hyperparameter Tuning** project.

The screenshots document the machine learning workflow, from dataset inspection and data preparation to model comparison, evaluation, and saving the trained model.

## Screenshots

### 1. Dataset Information — `output 1.png`

Displays the initial dataset analysis, including:

- Dataset loading and dimensions
- Column names and data types
- Missing value analysis
- Duplicate record analysis
- Statistical summary
- Target variable distribution
- Zero values in selected medical measurement columns

### 2. Data Preparation — `output 2.png`

Shows the preparation of the dataset for machine learning, including:

- Input features and target variable
- Feature and target dimensions
- Training and testing dataset sizes

### 3. Model Optimization and Comparison — `output 3.png`

Displays the hyperparameter tuning and cross-validation results for five classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

The output compares the best cross-validation accuracy achieved by each algorithm and identifies the selected model.

### 4. Model Evaluation and Final Results — `output 4.png`

Presents the final evaluation results of the selected model, including:

- Test accuracy
- Precision
- Recall
- F1-score
- Classification report
- Confusion matrix
- Confirmation that the trained model was saved successfully

The screenshot also shows the final project summary and successful completion of the workflow.

## Additional Visualizations

### Algorithm Comparison — `Algorithm_Comparison.png`

A horizontal bar chart comparing the best cross-validation accuracy of the five classification algorithms.

### Confusion Matrix — `Confusion_Matrix.png`

A visualization of the selected model's predictions compared with the actual target labels, showing correct and incorrect classifications.

## Purpose

These screenshots provide visual evidence of the project's implementation and demonstrate the complete machine learning workflow, from dataset analysis to final model evaluation.
