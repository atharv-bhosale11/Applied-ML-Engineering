# Iris Flower Classification

## Overview

This project implements Iris Flower Classification using Machine Learning algorithms. The dataset is preprocessed, analyzed, and used to train classification models for predicting iris flower species.

## Dataset 

The Iris dataset contains the following features:

- Sepal Length (cm)
- Sepal Width (cm)
- Petal Length (cm)
- Petal Width (cm)

Target Variable:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- Scikit-Learn

## Machine Learning Models

- K-Nearest Neighbors (KNN)
- Decision Tree Classifier

## Project Workflow

1. Load Dataset
2. Data Cleaning
3. Missing Value Analysis
4. Statistical Summary
5. Class Distribution Analysis
6. Label Encoding
7. Feature and Target Preparation
8. Train-Test Split
9. Model Training
10. Model Evaluation
11. Model Comparison

## Performance Metrics

- Accuracy Score
- Classification Report
  - Precision
  - Recall
  - F1-Score
