# Project Screenshots

This folder contains screenshots of the outputs generated during the Titanic Survival Prediction project using Logistic Regression.

## Screenshot Information

### 1. Confusion Matrix

**File Name:** `Confusion_Matrix.png`

Displays the confusion matrix generated after evaluating the Logistic Regression model.

The matrix shows the comparison between:

- Actual Class
- Predicted Class

### 2. Age Distribution

**File Name:** `Distribution Graph.png`

Displays the age distribution of passengers in the Titanic dataset using a histogram.

### 3. Survival Count

**File Name:** `Count Graph.png`

Displays the number of passengers who survived and did not survive.

- `0` → Did Not Survive
- `1` → Survived
