# Dataset

This folder contains the dataset used for the Titanic Survival Prediction project using Logistic Regression.

## Dataset Information

- Dataset Name: Titanic Dataset
- File Name: Titanic.csv
- Target Variable: Survived
- Problem Type: Binary Classification
- Algorithm Used: Logistic Regression
 
## Dataset Description

The dataset contains passenger-related information that can be used to predict whether a passenger survived the Titanic disaster.

The target variable `Survived` represents the survival outcome.

- `0` → Did Not Survive
- `1` → Survived

## Dataset Usage

The dataset is used for:

- Data Cleaning
- Missing Value Analysis
- Feature Preparation
- Categorical Feature Encoding
- Feature Scaling
- Model Training
- Model Evaluation

## Data Preparation

The dataset is processed before training the Logistic Regression model.

The preprocessing workflow includes:

1. Loading the dataset
2. Cleaning the data
3. Handling missing values
4. Encoding categorical features
5. Separating features and target
6. Splitting data into training and testing sets
7. Performing feature scaling
