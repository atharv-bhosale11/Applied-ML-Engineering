# 🤖 Trained Machine Learning Model

This directory is intended to store the trained machine learning model for the California Housing Price Prediction project.

## 📁 Model Information

- **Model File:** `BestHousingModel.pkl`
- **Model Type:** Regression
- **Purpose:** Predicts median house values in California using housing and demographic features.

## ⚠️ Model File Availability

The trained model file (`BestHousingModel.pkl`) could not be uploaded to this GitHub repository because of its large file size, approximately **282,780 KB (~282.78 MB)**.

GitHub has a **25 MiB limit for files uploaded through the web interface**. The model exceeds this limit, so it has not been included in this directory.

## 🔄 How to Obtain the Model

You can generate the trained model by running the project's Python source code:

`src/californiahousingpriceprediction.py` 

The script trains and evaluates machine learning models and saves the selected model.
