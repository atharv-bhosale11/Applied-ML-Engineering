# 📸 Project Screenshots

This directory contains screenshots demonstrating the execution and evaluation of the California Housing Price Prediction project.

## 📊 Visualizations

- `MAE_Comparison.png` — Compares regression models using Mean Absolute Error (MAE).
- `R2_Comparison.png` — Compares regression models using R² scores.
- `RMSE_Comparison.png` — Compares regression models using Root Mean Squared Error (RMSE).
- `Residual_Plot.png` — Visualizes prediction residuals to analyze model errors.
- `Scatter_Plot.png` — Compares actual and predicted house prices.

## 💻 Execution Results

- `output 1.png` — Displays dataset information, missing values, duplicate records, and dataset validation.
- `output 2.png` — Shows cross-validation results and regression model performance comparisons.
- `output 3.png` — Displays hyperparameter tuning, final model evaluation metrics, and project execution summary.

## 🎯 Purpose

These screenshots provide visual evidence of the machine learning workflow, model comparison, prediction performance, and successful project execution.
