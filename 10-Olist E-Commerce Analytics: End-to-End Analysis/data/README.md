# Olist E-Commerce Dataset

## 📌 Dataset Overview

This folder contains the datasets used in the Olist E-Commerce Data Science Project.

The Olist Brazilian E-Commerce Public Dataset contains information about customers, orders, products, sellers, payments, reviews, and geolocation. These datasets can be used to analyze e-commerce operations, customer behavior, sales performance, and delivery efficiency.

## 📂 Datasets Included

### 1. olist_customers_dataset.csv 
Contains customer information, including:
- Customer ID
- Unique customer ID
- ZIP code prefix
- City
- State

### 2. olist_geolocation_dataset.csv
Contains geographical information, including:
- ZIP code prefix
- Latitude
- Longitude
- City
- State

### 3. olist_order_items_dataset.csv
Contains information about products purchased in each order, including:
- Order ID
- Product ID
- Seller ID
- Shipping limit date
- Price
- Freight value

### 4. olist_order_payments_dataset.csv
Contains payment information, including:
- Order ID
- Payment type
- Number of payment installments
- Payment value

### 5. olist_order_reviews_dataset.csv
Contains customer feedback and review information, including:
- Review ID
- Order ID
- Review score
- Review comments
- Review creation date
- Review answer timestamp

### 6. olist_orders_dataset.csv
Contains order lifecycle information, including:
- Order ID
- Customer ID
- Order status
- Purchase timestamp
- Approval timestamp
- Carrier handover timestamp
- Customer delivery timestamp
- Estimated delivery date

### 7. olist_products_dataset.csv
Contains product information, including:
- Product ID
- Product category
- Product name length
- Product description length
- Product photos quantity
- Product weight
- Product dimensions

### 8. olist_sellers_dataset.csv
Contains seller information, including:
- Seller ID
- ZIP code prefix
- City
- State

### 9. product_category_name_translation.csv
Contains translations of Portuguese product category names into English.

## 🛠️ Usage

These datasets are used in the Olist E-Commerce Data Science Project for:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer segmentation using RFM analysis
- Late delivery prediction using Machine Learning
- Customer satisfaction analysis
- Product category sales analysis
- State-level delivery performance analysis
- Business intelligence reporting using Power BI
