# Olist E-Commerce Dataset

## 📌 Dataset Overview

This folder contains the datasets used in the Olist E-Commerce Data Science Project.

The datasets contain information about customers, geolocation, orders, payments, reviews, products, sellers, and product category translations.

## 📂 Datasets Included

1. **olist_customers_dataset.csv** — Customer information, including customer IDs, ZIP code prefixes, city, and state.

2. **olist_geolocation_dataset.csv** — Geolocation information, including ZIP code prefixes, latitude, longitude, city, and state.

3. **olist_order_items_dataset.csv** — Order item details, including product IDs, seller IDs, prices, freight values, and shipping dates.

4. **olist_order_payments_dataset.csv** — Payment information, including payment type, payment installments, and payment value.

5. **olist_order_reviews_dataset.csv** — Customer review information, including review scores and review comments.

6. **olist_orders_dataset.csv** — Order information, including order status, purchase timestamp, approval timestamp, delivery dates, and estimated delivery dates.

7. **olist_products_dataset.csv** — Product information, including product categories, dimensions, weight, and other product attributes.

8. **olist_sellers_dataset.csv** — Seller information, including seller IDs, ZIP code prefixes, city, and state.

9. **product_category_name_translation.csv** — Translations of Portuguese product category names into English.

## 🛠️ Usage

These datasets are used for:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer segmentation using RFM analysis
- Late delivery prediction using Machine Learning
- Customer satisfaction analysis
- Product category sales analysis
- State-level delivery performance analysis
- Business intelligence reporting using Power BI

## ⚠️ Note

Keep all nine dataset files in this folder so the main Python script can load them using the configured file paths.

## 📜 Data Source

Olist Brazilian E-Commerce Public Dataset.
