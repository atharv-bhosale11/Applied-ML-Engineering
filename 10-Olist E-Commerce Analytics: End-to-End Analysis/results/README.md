# Olist E-Commerce Analysis Results

## 📌 Overview

This folder contains CSV files generated during the Olist E-Commerce Data Science Project. These files summarize key business insights obtained through data analysis and customer segmentation.

The outputs can be used for further analysis, reporting, and visualization using tools such as Microsoft Power BI.

## 📂 Output Files

### 1. `state_delivery_performance.csv`

Contains state-level delivery performance information.

**Purpose:**

* Analyze delivery performance across different states.
* Identify geographical differences in delivery outcomes.
* Support regional logistics and delivery performance analysis.

### 2. `product_category_sales.csv`

Contains sales information summarized by product category.

**Purpose:**

* Analyze sales performance across product categories.
* Identify categories contributing significantly to sales.
* Support product performance analysis and business reporting.

### 3. `rfm_customer_segments.csv`

Contains customer segmentation results based on RFM analysis.

RFM stands for:

* **Recency:** How recently a customer made a purchase.
* **Frequency:** How often a customer made purchases.
* **Monetary:** How much a customer spent.

**Purpose:**

* Understand customer purchasing behavior.
* Identify different customer segments.
* Support customer retention and marketing strategies.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Microsoft Power BI

## 📊 Usage

These CSV files can be imported into Microsoft Power BI, Excel, or Python for further analysis and visualization.

## 📌 Note

These files contain processed analytical results generated from the Olist Brazilian E-Commerce Public Dataset. Their contents depend on the data processing and analysis performed by the project script.
