# Project Images

This folder contains visualizations and execution output images generated during the Credit Card Fraud Detection project.

## Visualizations

| Image Name | Description |
|---|---|
| `EDA_Analysis.png` | Visualizes transaction class, amount, and time distributions. |
| `Feature_Importance.png` | Displays the top 15 most important features. |
| `Final_Confusion_Matrix.png` | Shows the final model's classification results. |
| `LogisticRegression_ConfusionMatrix.png` | Shows the baseline Logistic Regression confusion matrix. |
| `Logistic_Regression_Confusion_Matrix.png` | Displays Logistic Regression classification results. |
| `Logistic_Regression_Confusion_Matrix_Final.png` | Shows the final Logistic Regression confusion matrix variant. |
| `Logistic_Regression_Confusion_Matrix_Gradient_Boosting.png` | Stores a confusion matrix image associated with model evaluation. Verify the generating model before relying on this filename. |
| `Logistic_Regression_Confusion_Matrix_Tuned.png` | Displays the tuned Logistic Regression confusion matrix. |
| `Precision_Recall_Curve.png` | Shows the precision-recall curve for the tuned model. |

## Execution Output Images

| Image Name | Description |
|---|---|
| `output 1.png` | Dataset information and structure. |
| `output 2.png` | Dataset validation and statistical summary. |
| `output 3.png` | Dataset validation, exploratory data analysis, and data splitting. |
| `output 4.png` | Baseline Logistic Regression evaluation and additional model training. |
| `output 5.png` | Model comparison, hyperparameter tuning, cross-validation, and final evaluation. |
| `output 6.png` | Prediction error analysis, results saving, and successful project completion. |

## Purpose

These images document the project's exploratory data analysis, feature importance, model evaluation, and execution workflow.

They provide visual evidence of the machine learning process and help readers understand the model's performance.

## Notes

- All images are generated from the Credit Card Fraud Detection project.
- Confusion matrices show the numbers of true negatives, false positives, false negatives, and true positives.
- The Precision-Recall Curve helps evaluate fraud detection performance on an imbalanced dataset.
- Execution output images document important stages of the project.
